# Submission files

The reviewed final trade-off report is `TicketRoute_Tradeoff_Report.md` and its
HTML rendering. The submission package also provides the final DOCX and PDF
under `01_Report/`, and the recorded MP4 under `02_Demo/`.

Files containing `DRAFT` are automatically generated workflow records retained
for reproducibility. They are not the reviewed report to upload for marking.

`TicketRoute_Read_Aloud_EN.txt` is the final recorded narration, and
`TicketRoute_Demo_EN.srt` contains the video's English captions.
